# Feishu Admin AI Bot

面向飞书的企业智能助理项目。系统将用户的自然语言请求转换为受权限、参数和执行步数约束的工具调用，连接飞书办公能力与电商业务 MCP，完成数据查询、分析和结果交付。

## 项目背景

企业日常工作分散在即时沟通、云文档、日历、审批和业务系统中。一个看似简单的需求，例如“查询客户订单并总结消费偏好，再发到群里”，通常需要员工在多个系统之间切换，手动查询、整理和发送。

传统聊天机器人只能回答问题，无法稳定调用真实业务工具；让大模型自由操作，又可能出现工具选择错误、参数编造、身份越权和结果误报。

本项目通过 Java/Spring Boot 构建飞书企业智能助理：

- Java 服务负责事件接入、权限校验和任务编排
- 大模型负责意图识别和工具规划
- 飞书 CLI 执行飞书办公操作
- 电商 MCP 提供结构化业务数据
- MySQL 保存会话记忆、用户授权信息和工作流配置
- Java 侧对白名单、身份、参数和执行结果进行最终校验

项目重点是让大模型的实际操作具备可控性、可追踪性和可诊断性。

## 核心能力

- 接收飞书群聊和私聊消息事件
- 针对原消息回复，并在群聊中 @ 触发用户
- 通过 `lark-cli` 执行飞书办公操作
- 通过电商 MCP 查询商品、库存、订单和退款数据
- 通过数据库工作流执行固定业务流程
- 支持用户 OAuth 授权和用户身份操作
- 保存群聊、私聊近期记录和历史摘要
- 支持会话记忆压缩，减少上下文长度
- 对工具、参数、身份和命令执行进行 Java 侧校验
- 限制 Agent 和 CLI 最大执行步数
- 使用消息 ID、会话 ID 和线程 ID串联完整日志

## 技术栈

- Java 17
- Spring Boot 3
- Maven
- MySQL
- Docker Compose
- 飞书开放平台
- `lark-cli`
- 电商 MCP Server
- 大语言模型 API
